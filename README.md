# ✈️ Airline & Airfare Analytics

## 📌 Project Overview

Airline & Airfare Analytics is a data analytics project that explores flight pricing, airline performance, route patterns, and booking behavior using Python, SQL, SQLite, and Power BI.

The project aims to identify pricing patterns and analyze flight trends through data cleaning, exploratory data analysis, SQL queries, and interactive dashboards.

**Note:** The dataset used in this project is synthetic and created for learning and analytical practice. It does not represent actual airline schedules or live ticket prices.

## 🎯 Project Objectives

- Analyze flight distribution across airlines.
- Compare average ticket prices between airlines.
- Explore ticket prices across travel classes.
- Analyze ticket prices based on the number of stops.
- Identify frequently represented flight routes.
- Analyze monthly flight trends.
- Explore booking periods and average ticket prices.
- Examine the relationship between flight distance and ticket price.
- Compare airline ratings.
